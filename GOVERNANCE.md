# Governance

**Sole maintainer:** Maxim Kich (Maxim Shevchenko-Tymchuk), GitHub `@maxim-kich`.

The maintainer decides product direction, accepts or declines contributions, merges PRs and publishes releases. There is no committee, voting process, or automatic path to write access. Contributors are credited without becoming maintainers.

Bug reports and scoped proposals belong in GitHub Issues. Security reports follow SECURITY.md. Large feature work needs an agreed scope first. Decisions should be explained in the relevant issue or PR when practical.

The maintainer may defer or close work that exceeds the project's scope or review capacity. Forking and redistribution are permitted under the MIT license. No project policy narrows that license.
