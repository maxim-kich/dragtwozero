# Security

Report vulnerabilities privately to **i.am@maximshechenko.com** with the subject “Drag 2.0 security report”. Do not put sensitive content, credentials, or exploitable details in a public issue.

Include the app/macOS version, reproduction steps, impact, and a minimal example using synthetic data. Do not send your real clipboard contents or private documents.

The latest public release is the supported line. There are no public releases yet; while 0.0.1 is being prepared, reports against the current source are welcome. This is a solo-maintained project without a guaranteed response time or bug-bounty program.

Please coordinate public disclosure with the maintainer so a fix can be prepared. Do not access other users' data or disrupt systems while testing.
